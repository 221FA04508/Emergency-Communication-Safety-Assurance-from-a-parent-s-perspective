## ✨ Features

### 🚨 Real-Time Emergency Alerts

* Sends instant alerts during campus incidents
* Notifies parents with **live updates and safety status**

### 📱 Smart Parent Notification System

* Personalized alerts based on student data
* Ensures **quick and reliable communication**

### 🤖 Agentic AI Communication

* Uses AI agents (CrewAI concept) to generate meaningful alerts
* Automates decision-making during emergencies

### ⚡ Fast Response Coordination

* Improves communication between **campus authorities and parents**
* Reduces delay in critical situations

### 🔐 Secure Communication

* Ensures privacy and secure transmission of alerts
